# hoja-partido

Hoja de partido para entrenadores de fútbol base: alineaciones por cuartos, marcador, banquillo y resumen para compartir por WhatsApp.

## Abrir la app

👉 **https://entrenadormanuel68-png.github.io/hoja-partido/**

Desde el móvil, usa "Añadir a pantalla de inicio" para abrirla como una app.

Las plantillas y el partido se guardan en cada dispositivo (no se sincronizan entre móviles).

## Hoja de campo A4 (4 cuartos)

En la pestaña **Resumen**, el botón **📄 Hoja A4 (4 cuartos)** genera una hoja en tamaño A4 con el campo de los cuatro cuartos, el marcador de cada uno, el banquillo y los cuartos jugados por cada jugador. Desde esa hoja puedes:

- **🖨 Imprimir / PDF**: imprime en A4 o guarda como PDF (elige «Guardar como PDF» en el diálogo de impresión).
- **📱 Compartir imagen**: envía la hoja como imagen por WhatsApp u otra app. Si el navegador no permite compartir, la descarga.
- **⬇ Guardar imagen**: descarga la hoja como PNG.

## Copia de seguridad y cambio de móvil

En la pantalla **⚙ Plantilla** hay dos botones para mover las plantillas guardadas:

- **⬇ Exportar plantillas**: guarda todas las plantillas en el archivo `plantillas-hoja-partido.json`. En el móvil abre el menú de compartir; si no está disponible, descarga el archivo.
- **⬆ Importar plantillas**: lee un archivo `.json` exportado y añade sus plantillas a las que ya tienes. Si alguna se llama igual, pregunta si quieres sustituirla o conservar la tuya.

Solo se exportan las plantillas, no el partido en curso.

## Actualizaciones

La app funciona sin conexión. Cuando se publica una versión nueva, llega la siguiente vez que se abre con internet; si no ves los cambios, cierra la app por completo y vuelve a abrirla.
